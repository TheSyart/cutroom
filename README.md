# Cutroom

![Cutroom · AI 视频剪辑工作台](assets/brand/repository-cover.webp)

Cutroom 是 macOS 上的开源 AI 视频剪辑工作台。把口播或录屏导入工程，告诉 Agent 哪些内容值得保留。确认剪法后，可以边看草稿边提修改，也可以自己接手时间线，剪好后导出 MP4。

[从源码启动](#从源码启动) · [第一次剪辑](docs/user/getting-started.md) · [文档中心](docs/README.md)

## 剪第一条视频

1. **导入素材。** 在首页新建工程，点「导入素材」选择视频、图片或音频。双击素材或将它拖到时间线，就能播放、拆分和修剪。
2. **告诉 Agent 怎么剪。** 在「设置 › 剪辑模型」配置支持工具调用和读图的模型，然后在右侧对话里说：「把这段口播里的重复试讲剪掉，保留最后一次完整演示，给保留下来的台词加字幕。」核对剪辑思路并确认，Agent 会在独立草稿上执行。
3. **回看并导出。** 在播放器切换「当前工程」和「Agent 草稿」对照剪口。想改某一句时，右击对应的字幕或片段，点「添加到对话」。也可以直接拖动剪口、改字幕或调音量。定稿后点顶栏「导出 MP4」。

## 让 Agent 在画面上绘制动效

在对话输入框的 **「＋」** 菜单打开「动效绘制」。例如，选中一句口播添加到对话，然后说：「在这句旁边画出请求从 Agent 发到工具、再返回的过程。」

节点和箭头会随绘制进度出现在播放器中。拖动播放头可以随时接管预览，点「跟随绘制」即可回到最新一步。展开时间线的「动效」轨，可以选中某根箭头单独提修改，也可以移动、修剪或拆分整幕。在空工程里也能制作全屏动效短片。

## 从源码启动

准备一台 Mac，安装 Git、Node.js 22 或更新版本，以及 Xcode 26 或更新版本和配套的 macOS SDK。在终端运行：

```sh
git clone https://github.com/TheSyart/cutroom.git
cd cutroom
./启动.command
```

首次启动会安装项目依赖、构建桌面应用并打开工作台。手动剪辑可以直接开始。使用转写和导出时，在「设置 › 媒体与转写」检查所需工具：

| 用途           | 本机需要准备的内容                                                                                                                    |
| -------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| 导出 MP4       | 通过 `brew install ffmpeg-full` 安装 FFmpeg 和 ffprobe，烧录字幕需要 subtitles 滤镜。                                                 |
| 本地语音转字幕 | 另装 `brew install whisper-cpp`，下载 [ggml 模型](https://huggingface.co/ggerganov/whisper.cpp/tree/main)，在设置里选择 `.bin` 文件。 |
| 云端语音转字幕 | 在设置里启用阿里云 Fun-ASR 并填写北京地域 API Key。转写时会将提取的音轨发给该服务。                                                   |

## 工程保存在哪里

每个工程都是一个文件夹。`timeline.json` 保存时间线，`assets/` 保存导入的素材，隐藏目录 `.cutroom/` 保存工程修订、转写、动效和精剪草稿。备份时复制整个工程文件夹。模型配置、会话和可重建的媒体缓存有各自的本机位置，见[存储与迁移](docs/architecture/global-state-store.md)。

## 开发与许可

本地运行 `make check` 检查代码并执行测试。开发环境、模块分工和真实 Electron 验收命令见[开发指南](docs/development/README.md)。安装预览版前，可按[安装包核验说明](docs/release/unsigned-preview-notice.md)检查下载文件。
