# 常见问题

> 文档状态：Active<br>
> 面向读者：剪辑用户、支持人员<br>
> 最后核验：2026-11-20<br>
> 事实源：[媒体设置](../../desktop/src/renderer/src/components/settings/mediaAnalysis/)、[桌面日志](../../desktop/src/main/)

| 遇到的问题                     | 处理方法                                                                                                    |
| ------------------------------ | ----------------------------------------------------------------------------------------------------------- |
| 工程能打开，但某段视频无法播放 | 在素材库重新定位对应文件。优先选择同一份原片。用 ffprobe 校验替换视频的时长。                               |
| 本地转写缺依赖                 | 打开「设置 › 媒体与转写」，核对 ffmpeg、whisper-cli 和 Whisper 模型文件。指定模型时选择 `.bin` 文件。       |
| 云端转写鉴权失败               | 核对 Fun-ASR 的地域与凭据。转写密钥在「设置 › 媒体与转写」中填写，对话模型的凭据在「设置 › 剪辑模型」管理。 |
| 关键帧无法交给模型             | 核对当前模型的图片输入能力，以及发送关键帧时的授权。                                                        |
| MP4 导出失败                   | 核对 ffmpeg、ffprobe、素材在线状态和输出目录的可写权限。                                                    |
| 首次启动报告配置占用或冲突     | 退出旧版，备份两边的目录，再按[配置冲突与恢复](../architecture/global-state-store.md)核对。                 |

排查时记录应用版本、使用的转写方式、故障发生的步骤和界面报错。正式配置的日志在 `~/Library/Logs/Cutroom`，试用配置的日志在其数据目录下的 `logs/`。分享日志片段前请去掉密钥、私人路径、对话与素材内容。
