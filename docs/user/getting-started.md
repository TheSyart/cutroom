# 第一次剪辑

> 文档状态：Active<br>

> 事实源：[编辑器界面](../../desktop/src/renderer/src/components/editing/)、[根目录使用说明](../../README.md)

## 建立工程

在项目首页新建工程或选择已有工程文件夹。将素材导入素材库，再拖到时间线。素材库按工程隔离。导入后请保留工程里的 `assets/`。离线素材可以从素材面板重新定位，视频需要通过时长校验。

播放头决定预览位置。选中片段可以拆分、修剪或调节音量。上层画面覆盖下层，单独的音轨可以放配乐和旁白。先检查画面、原声与字幕的对齐，再从顶栏导出 MP4。导出需要本机安装 ffmpeg 和 ffprobe。

## 生成字幕与转写

在「设置 › 媒体与转写」查看依赖。使用本地 Whisper 时，安装 `whisper-cli` 并选择 ggml 模型文件。使用阿里云 Fun-ASR 时填写北京地域的 API Key，转写会把提取的音轨发送给该服务。生成字幕后可以直接修改字幕文本、时间与样式。需要清理媒体代理、缩略图、波形及关键帧时，使用「设置 › 媒体与转写 › 媒体缓存 › 清理缓存」。

## 使用项目 Agent

在「设置 › 剪辑模型」配置模型。右侧 Agent 使用当前工程的会话。右击片段、字幕、轨道或时间选区，选择「添加到对话」即可指定修改位置。发送素材关键帧前可以在审批卡上查看接收模型与时间点。

进行「口播与画面精剪」时，先核对 Agent 提出的剪法，再批准草稿制作。可以切换工程与草稿预览，检查关键片段、字幕和混音。动效绘制从输入框的加号菜单开启，绘制状态按工程保存。完成后可在时间线上继续手动编辑。

迁移电脑或备份时，请同时考虑工程、全局会话及密钥，具体位置见[存储与迁移](../architecture/global-state-store.md)。
