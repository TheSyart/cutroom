# 组件与编辑状态

> 文档状态：Active<br>
> 面向读者：设计者、开发者<br>
> 最后核验：2026-11-20<br>
> 事实源：[组件实现](../../desktop/src/renderer/src/components/editing/)、[编辑状态](../../desktop/src/renderer/src/components/editing/editingStore.ts)

素材库处理导入、失联和重新定位。播放器按播放头合成活动片段与字幕。时间线处理选择、修剪、拆分、移动与跨轨拖放。参数检查器读取当前选择。修改这些入口时，让同一工程命令负责更新修订和撤销历史，再验证工程重开后的表现。

时间线引用需要携带对象身份与时间范围，避免仅把片段的显示名称发给 Agent。文案和反馈应能区分正在编辑的工程版本、Agent 草稿及已交付版本。
